This project includes scripts used in the analyses reported in the "Neural tracking of biological motion rhythms in early infancy: links to caregiver touch-related behaviours and attitudes" manuscript

#BioMot_forplots.m

This script can be used to generate plots, including EEG amplitude spectra. 

#BioMot_fortable.m

This script generates tables with data for further statistical analyses. 

#biomot_EEG_stats.R

This script includes statistical analyses of the EEG data.

#biomot_lookingbehavior_stats.R

This script includes statistical analyses of the looking behavior data.

Datasets can be accessed under this link: https://doi.org/10.17605/OSF.IO/THFYE
